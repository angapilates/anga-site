# Site do Angá Pilates

Landing page do Angá Pilates (Pilates Clássico em Capim Macio, Natal/RN).
Publicada pelo GitHub Pages no domínio angapilates.com (registrado na Hostinger). Cada envio para o branch `main` atualiza o site.

- `index.html`: a página
- `img/`: fotos e logos
- `video/`: vídeo de depoimentos e capa
